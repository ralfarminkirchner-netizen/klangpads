# KlangPads

Kindgerechte Musikmaschine — große MPC-Pads, Loops, Muster, Aufnahme.
Schwester von [LOOPTiSCH](https://ralfarminkirchner-netizen.github.io/looptisch/), eigenes Gesicht.

## Spielen

- Lokal: `python3 server.py` → http://127.0.0.1:8787/
- GitHub Pages (nach Aktivierung): https://ralfarminkirchner-netizen.github.io/klangpads/
- Railway: dieses Repo im Dashboard verbinden. `Procfile` + `railway.json` sind fertig. `HOST=0.0.0.0`.

## Bedienung

1. Bildschirm tippen — Ton an.
2. Pads spielen. Darunter 16 Schritte für das gewählte Pad.
3. ▶ spielt das Muster im Kreis. ● nimmt im Takt auf.
4. Kits wechseln: Schlag, Flöte, Glocken, Bass, Wald, Stimme.
5. **Zauber** passt Samples ans Tempo an.
6. Eigenes Bild: Foto auf den Hintergrund ziehen = Vollbild-Cover.
7. Mikro oder Datei auf ein Pad legen.
